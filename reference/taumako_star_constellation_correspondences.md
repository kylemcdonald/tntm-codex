# Taumako Star and Constellation Name Correspondences

Western names are left blank where I did not find a clear Western equivalent. Some entries are culturally named asterisms rather than one-to-one matches with official Western constellations.

| Taumako name | Western name | Notes |
|---|---|---|
| Hakangi | Orion's shoulders | Also described as a V-shaped seven-star constellation; paired with Hetu Mdavo as `Hetu e Lua` in TNTM notes. |
| Hetu Mdavo / Hetumdavo | Pleiades | Named directly in the papers and additional sources as the Pleiades star group. |
| The Return of Hetu Mdavo | Pleiades | Refers to navigation by Hetu Mdavo when it is below the horizon, not a separate body. |
| Hetu e Lua |  | Pairing of Hetu Mdavo and Hakangi. |
| Takelo | Orion's Belt | Identified repeatedly as Orion's Belt. |
| Te Huangi / Te Longi | Orion's shoulders | Vaeakau-Taumako name found in additional web/PDF search. |
| Lolei | Orion's knees | Vaeakau-Taumako name found in additional web/PDF search; PDF text renders macrons inconsistently. |
| Sino / Tino | Sirius | Identified as Sirius in the Vaeakau-Taumako wind compass PDF, the Polynesian Star Catalog, TNTM notes, and the Feinberg and Genz article; in this use it is the body of Manu. |
| Sino | Aldebaran | The Tupaia article identifies `sino` as the partner star of `salo lavoi`, i.e. Aldebaran in Taurus, while noting that Sino is also used for Sirius in Taumakoan Manu traditions. |
| Te Manu / Manu |  | Bird constellation centered on or associated with Sino/Sirius. |
| Nga Papakau / Nga Kapakau | Canopus and Procyon | Arms/wings of Manu; source does not clearly map which Taumako arm-name is Canopus versus Procyon. |
| Te Papakau Nga Ndeni / Papakau Ndeni | Canopus or Procyon | One arm/wing of Manu; Feinberg and Genz translate this as "The Ndeni Arm" but do not assign it individually to Canopus or Procyon. |
| Te Papakau a Tatou / Papakau | Canopus or Procyon | One arm/wing of Manu; Feinberg and Genz translate this as "Our Arm" but do not assign it individually to Canopus or Procyon. Diagram spelling also appears close to `Papa Kau`/`Papakuu`. |
| Te Kau Akona / Kaua Kona | Southern Cross | The wind compass PDF gives `Te Kau Akona` as Southern Cross; TNTM diagram text appears close to `Kaua Kona`. |
| LuooNa'i / Luona'i | Pointer stars of the Southern Cross | Identified in supporting TNTM notes as the two pointer stars. |
| Salo / Talo / Taro | Antares | Additional sources identify Salo/Talo/Taro as Antares; Taumako speakers may shift initial `t` to `s`. |
| Salo Lavoi | Antares in Scorpio; top seven stars of Scorpio/Scorpius | The papers identify Salo Lavoi as the top seven stars of Scorpio; the Tupaia article identifies it as a Taumakoan name for Antares in Scorpio. |
| Salo Tapio |  | Taro-without-fruit star picture. |
| Lau |  | Leaves in the Salo taro star picture. |
| Ohaa |  | Fruit/corm in the Salo taro star picture. |
| Te Kilika / Kilika | Tail of Scorpius | Feinberg and Genz gloss this as "The Shark" and identify it with Scorpius's tail. |
| Lua Tawawa |  | Diagram label also appears as `Lua Tewawa`/`LuaTewawa`. |
| Paekea me Ula |  | Paired dark crab-like and lobster/crayfish-like shapes. |
| Paekea |  | Crab-like dark shape; part of `Paekea me Ula`. |
| Ula |  | Lobster/crayfish-like dark shape; part of `Paekea me Ula`. |

## Sources Checked

Primary local sources checked: all PDFs in this folder, especially `George - Te Lapa.pdf`, `Lata's Wayfinding System and Climate Science.pdf`, `George - Seafaring in the Polynesian Outliers.pdf`, and `PN Final Draft CambridgeSF again HALF MG SPfeb1.pdf`.

Additional PDFs downloaded to `additional/`:

| File | Use |
|---|---|
| `additional/vaeakau-taumako-wind-compass.pdf` | Confirms Salo/Talo/Taro = Antares, Sino/Tino = Sirius, Takelo = Orion's Belt, Te Kau Akona = Southern Cross, Hetumdavo = Pleiades, and Hakangi = Orion's shoulders. |
| `additional/polynesian-star-catalog-2014-revised.pdf` | Confirms Taumako entries for Hetu Mdavo, Takelo, and Sino in a broader Polynesian star-name catalog. |
| `additional/feinbergand2012.pdf` | Confirms Talo/Salo = Antares, Te Kilika = Scorpius's tail, Hetumdavo = Pleiades, Takelo = Orion's Belt, Manu = Sirius, Nga Papakau/Kapakau = Canopus and Procyon, Sino/Tino = Sirius, Te Huangi/Te Longi = Orion's shoulders, and Lolei = Orion's knees. |
| `additional/Tupaia s Wind Positioning System   Re Modelling Ancestral Polynesian Voyaging.pdf` | Confirms Salo Lavoi = Antares in Scorpio and adds the partner-star identification Sino = Aldebaran in Taurus, while noting Sino is also Sirius in Taumakoan Manu traditions. |
